## Fonctionnalités de Quartz

Quartz supporte plusieurs fonctionnalités intéressantes :

1. Les équations LaTeX : \[ E = mc^2 \]
2. Les diagrammes Mermaid :

```mermaid
graph TD
    A[Start] --> B{Decision}
    B -->|Yes| C[OK]
    B -->|No| D[Cancel]
```

3. La coloration syntaxique :

```python
def hello_world():
    print("Hello, World!")
```
